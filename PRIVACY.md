# Privacy Policy — Unified Account Colors

Last updated: 2026-09-25

Unified Account Colors is designed to work entirely inside Thunderbird.

## Data collection

The add-on does not collect, transmit, sell, share, or analyse personal data.

## Network access

The add-on performs no network requests and connects to no external service.

## Message data

The add-on does not read or transmit message bodies, attachments, recipients, sender addresses, subject lines, or message content.

## Local Thunderbird data

The add-on reads only the Thunderbird folder/account color values needed to display the native account indicator in unified message views. It does not maintain its own color database and does not modify Thunderbird's `folderTree.json` color configuration.

## Telemetry and analytics

No telemetry, analytics, advertising, tracking, or crash-reporting service is included.

## Permissions

The add-on uses a Thunderbird Experiment API because the required folder-color and `about:3pane` interfaces are internal Thunderbird APIs. This causes Thunderbird to display the broad Experiment API permission warning. The source code is public so the exact use of that access can be inspected.

## Contact

Please use the issue tracker in the public NalinForge source repository once published.
